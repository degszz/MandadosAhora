# Repartidores

Volver: [[00 Inicio]]

- `/repartidor`: explica el trabajo, la ganancia y pide registrarse con Google (nombre y foto reales, por seguridad del cliente).
- Al registrarse queda `role = repartidor`, `verified = false` → `/repartidor/espera`.
- El admin aprueba o rechaza en el tab **Repartidores** del admin.
- Verificado → `/repartidor/panel`.
- Toast "Buscamos repartidores" en todo el sitio: se prende con `settings.hiring_active` desde el header del admin.

Ganancia: ver [[Precios y comisiones]]. Entrega con código: ver [[Pedidos y entrega]].
